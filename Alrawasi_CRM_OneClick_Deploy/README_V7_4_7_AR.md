# V7.4.7 — إصلاح آمن لقائمة العملاء
تم بناء هذه النسخة من V7.4.5 التي كانت قائمة العملاء تعمل فيها.

التعديلات:
- تلوين contacted بالأزرق، interested بالأخضر، not_interested بالأحمر الفاتح، follow_up بالأصفر.
- استخدام شروط Jinja بسيطة وآمنة داخل البطاقة.
- حذف النص الافتراضي لخدمات التسويق الرقمي من تحديث العميل.
- كل حفظ لحالة العميل يسجل في جدول interactions الموجود مسبقاً مع user_id والحالة والملاحظة والتاريخ الافتراضي للجدول.
- لم يتم إنشاء قاعدة بيانات جديدة.
- لم يتم حذف أو إعادة ضبط المستخدمين أو السجل السابق أو المتابعات أو بيانات العملاء.
- خصائص V7.4.5 (الترقيم، الروابط، الشعارات عند توفرها) محفوظة.
