# V7.5.46 — المظهر الاحترافي الاختياري

المبدأ الأساسي:
- لم يتم تغيير المظهر المحفوظ لأي مستخدم.
- الحسابات القديمة تبقى على المظهر الحالي Classic تلقائياً.
- لا ينتقل المستخدم إلى المظهر الاحترافي إلا إذا اختاره بنفسه من «المظهر والرؤية».
- الاختيار والألوان محفوظة لكل مستخدم بنفس آلية التخزين الشخصية السابقة.

المظهر الاحترافي:
- شريط علوي منظم بألوان تلال الرواسي.
- شريط جانبي على اليمين.
- قوائم منسدلة تجمع الأوامر بدلاً من ازدحام الأزرار:
  * البيانات
  * الحماية والاستعادة
  * التحقق
- القوائم تشمل التصدير، نسخ البيانات، تحديث بيانات مقاول،
  حماية البيانات، استعادة البيانات، تحديث النظام،
  تدقيق أرقام العضوية وقوائم التحقق.
- صفحة الشركات أكثر ترتيباً مع بطاقات وفلاتر متناسقة.
- ألوان المظهر الاحترافي قابلة للتعديل لكل مستخدم:
  الخلفية، البطاقات، النص، العناوين، الشريط العلوي، لون التمييز والأزرار، وحجم العرض.

حماية البيانات:
- قاعدة البيانات crm.db.gz لم تتغير.
- لا تغيير في الشركات أو المستخدمين أو سجلات التواصل أو القوالب.
- حماية Neon/PostgreSQL بقيت كما هي.
