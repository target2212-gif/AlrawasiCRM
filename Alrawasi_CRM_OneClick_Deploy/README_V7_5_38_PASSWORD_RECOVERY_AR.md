# V7.5.38 — استعادة كلمة المرور

- أضيف زر «نسيت كلمة المرور؟» في صفحة الدخول.
- الاستعادة متاحة فقط لحسابات المدير النشطة.
- لا يتم كشف كلمة المرور القديمة؛ يتم إنشاء hash جديد فقط.
- رمز الاستعادة لا يُحفظ داخل GitHub. أنشئ في Render متغير بيئة باسم `ADMIN_RECOVERY_KEY` وضع فيه رمزاً سرياً طويلاً خاصاً بك.
- من صفحة «المستخدمون والمندوبون» يستطيع المدير تعيين كلمة مرور جديدة لأي مستخدم دون معرفة القديمة.
- الحد الأدنى لكلمة المرور الجديدة: 10 أحرف.
- لا توجد أي عمليات حذف أو استبدال للشركات أو سجلات التواصل في هذا التعديل.

## إعداد رمز الاستعادة مرة واحدة
Render > Service > Environment > Add Environment Variable
Key: ADMIN_RECOVERY_KEY
Value: رمز سري طويل تحتفظ به خارج GitHub.
ثم Save / Deploy.

إذا نسيت كلمة مرور المدير لاحقاً:
صفحة الدخول > نسيت كلمة المرور؟ > بريد المدير + رمز الاستعادة + كلمة مرور جديدة.
