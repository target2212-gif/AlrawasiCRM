# تلال الرواسي CRM V7.5.3

تحسينات الإدارة وإمكانية الوصول:
- تحسين تباين الوضع الداكن للأرقام والنصوص الثانوية والأزرار المعطلة والبطاقات.
- المدير يحدد المظهر الافتراضي لكل مستخدم عند الإنشاء أو التعديل، بما في ذلك حجم العرض 85%-160%.
- كل مستخدم يستطيع تخصيص مظهره محلياً ثم العودة إلى مظهر المدير الافتراضي.
- المدير يستطيع حذف مستخدم آخر؛ تُلغى تعييناته مع الاحتفاظ باسمه كسجل تاريخي في عمليات التواصل السابقة.
- لا يمكن للمدير حذف الحساب الذي يستخدمه حالياً.
- يمكن تغيير حالة الشركة في أي اتجاه، بما في ذلك الرجوع إلى «جديد»، ويسجل النظام الحالة القديمة والجديدة.
- المدير يستطيع حذف تسجيل تواصل أضيف بالخطأ.
- لا تغيير في بيانات دليل مقاول أو آلية الاستيراد التراكمي.
