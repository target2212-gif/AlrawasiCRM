# V7.5.6 — التواصل والانتقال المباشر للصفحات

- إعادة إظهار زر واتساب للشركات التي لديها رقم موثوق/محفوظ، مع الرسالة الجاهزة الخاصة بالمستخدم.
- إضافة زر بريد إلكتروني للشركات التي لديها بريد، مع عنوان ونص رسالة جاهزين.
- إضافة أزرار التواصل في بطاقات الشركات وفي صفحة الشركة.
- إضافة حقل للانتقال مباشرة إلى رقم صفحة مع الحفاظ على البحث والفلاتر وعدد الشركات في الصفحة.
- لا يتطلب REBUILD ولا يغير قاعدة البيانات أو المستخدمين أو إعدادات المظهر.
