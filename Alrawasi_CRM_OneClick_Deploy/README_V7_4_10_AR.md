# V7.4.10 — فتح بيانات الشركة داخل منصة مقاول

هذه النسخة مبنية مباشرة من V7.4.9.

التعديل:
- زر «صفحة مقاول» لا يفتح الموقع الرسمي للشركة.
- يفتح منصة مقاول نفسها في تبويب جديد.
- يبحث أولاً برقم عضوية مقاول الحقيقي المخزن للشركة.
- إذا لم يوجد رقم عضوية، يبحث باسم الشركة داخل دليل المقاولين.
- لا يتم استخدام CRM id أو source_id على أنه رقم ملف في مقاول.
- السبب: منصة مقاول الحالية تعرض تفاصيل المقاول داخل بطاقات دليل المقاولين، ولا نعتمد رابط ملف تفصيلي مخترع وغير موثق.
- لم يتم تغيير بيانات التواصل، الحالات، المستخدمين، أو سجل التفاعلات.
- خصائص V7.4.9 الخاصة بـ Google Phone Matching والنسخ الاحتياطي والتصدير بقيت كما هي.
