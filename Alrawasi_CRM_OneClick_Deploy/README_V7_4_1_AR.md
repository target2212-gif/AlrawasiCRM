# V7.4.1 — إصلاح خطأ Internal Server Error

سبب الخطأ في V7.4:
قالب صفحة الشركات كان يستدعي endpoint غير موجود باسم sync_muqawil_admin، بينما اسم الدالة الفعلي مختلف.
هذا يؤدي إلى BuildError أثناء رسم الصفحة، ولذلك تظهر صفحة Internal Server Error.

الإصلاحات:
- زر تحديث مقاول يفتح صفحة استيراد JSON الصحيحة مباشرة.
- تصحيح اسم المندوب في بطاقات الشركات.
- استخدام رابط واتساب الذي ينشئه CRM أصلًا.
- إغلاق نموذج توزيع العملاء بشكل صحيح.
- الإبقاء على التصنيف والدرجة والخريطة وواجهة البطاقات.
- لا يوجد أي حذف أو تعديل لحالات العملاء أو المستخدمين أو المتابعات.
