# تلال الرواسي CRM V7.5.2

إضافة إعدادات وصول ومظهر بدون تغيير بيانات CRM:
- تغيير خلفية النظام.
- تغيير خلفية البطاقات.
- تغيير لون النص والعناوين.
- تكبير/تصغير العرض من 85% إلى 160%.
- وضع داكن عالي الوضوح.
- خلفية مريحة للعين.
- حفظ الإعدادات لكل مستخدم على المتصفح نفسه عبر localStorage.
- استعادة الإعدادات الافتراضية.

لا توجد أي عملية حذف أو إعادة بناء لبيانات الشركات في هذا التحديث.
