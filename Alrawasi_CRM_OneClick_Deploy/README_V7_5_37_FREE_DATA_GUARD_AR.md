# CRM V7.5.37 — Free Data Guard

هذه نسخة Code + Seed آمنة للخطة المجانية في Render.

- لا تستبدل قاعدة التشغيل السليمة أثناء إعادة تشغيل نفس الـ instance.
- تتحقق من الجداول الأساسية و PRAGMA quick_check قبل اعتبار قاعدة التشغيل صالحة.
- نسخة JSON الكاملة تسجل نوع التخزين داخل الملف.
- زر JSON Snapshot يبقى الوسيلة الأساسية لحفظ التعديلات خارج Render Free.
- لا يوجد ادعاء بأن /tmp تخزين دائم: إذا أعاد Render إنشاء الـ instance من الصفر، يبدأ النظام من Seed المضمن في هذا الإصدار.
- لذلك بعد أي تنقيح مهم نزّل نسخة JSON فوراً واحتفظ بها خارج Render.
