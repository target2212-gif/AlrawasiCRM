# V7.4.3 — إصلاح فتح الشركة والأيقونات

سبب صفحة Not Found:
واجهة V7.4 كانت ترسل اسم الشركة وزر فتح الشركة إلى /companies/<id>
بينما المسار الحقيقي في التطبيق هو /company/<id>.

تم الإصلاح:
- اسم الشركة يفتح /company/<id>.
- زر «فتح الشركة» يفتح نفس المسار الصحيح.
- استبدال أيقونات/شعارات الشركات بأيقونة مبنى محلية تعمل بـ CSS ولا تعتمد على رابط صورة خارجي.
- استمرار إخفاء #رقم من اسم الشركة في العرض.
- لم يتم تعديل قاعدة بيانات العملاء أو حالات التواصل أو المستخدمين أو المتابعات.
