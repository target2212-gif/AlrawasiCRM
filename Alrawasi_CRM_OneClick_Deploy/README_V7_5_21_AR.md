# CRM V7.5.21
- إصلاح الترتيب والترقيم الديناميكي: أي شركة يضاف لها جوال/واتساب تنتقل فورًا إلى مجموعة الشركات ذات الجوال، ثم يعاد ترتيبها حسب التصنيف.
- رقم الشركة الظاهر في صفحة الشركة أصبح مشتقًا من نفس ترتيب دليل الشركات، وليس من SQLite id.
- إضافة تدقيق أرقام العضوية المكررة.
- تصدير قائمة الشركات ذات العضويات المكررة للتحقق من صفحة مقاول.
- استيراد تصحيح عضويات آمن بواسطة muqawilKey فقط، مع نسخة احتياطية ومعاملة rollback.
- لا يتم حذف أو تخمين أرقام العضوية تلقائيًا.
