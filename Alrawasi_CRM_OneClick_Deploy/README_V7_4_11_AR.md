# V7.4.11 — روابط بطاقات مقاول الحقيقية
مبني مباشرة من V7.4.9.

- يخزن رابط بطاقة مقاول الحقيقي بصيغة `/ar/contractors/<internal-id>/<type>`.
- مستورد JSON يقبل muqawilProfileUrl / profileUrl / contractorUrl / sourceUrl.
- لا يعتمد إلا رابط بطاقة مقاول حقيقي.
- زر «صفحة مقاول» يفتح البطاقة مباشرة عند توفرها.
- عند عدم توفرها يفتح دليل مقاول مفلترًا برقم العضوية الحقيقي أو اسم الشركة، ولا يفتح الموقع الرسمي للشركة.
- قيم MQ-xxxxx الاصطناعية لا تُعامل كرقم عضوية حقيقي.
- ترقيم CRM أصبح مستقلاً ومتسلسلاً.
- لا تغيير في سجل التواصل أو الحالات أو المستخدمين.

ملاحظة: بعض بيانات القاعدة الحالية نفسها اصطناعية (مثل source_id=muqawil_154 وعضوية MQ-20154).
هذه السجلات لا يمكن ربطها ببطاقة مقاول حقيقية قبل استيراد سجل حقيقي مطابق من المنصة.
