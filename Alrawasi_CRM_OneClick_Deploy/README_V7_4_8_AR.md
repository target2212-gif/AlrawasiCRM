# V7.4.8 — النسخ الاحتياطي والتصدير الكامل

تمت إضافة زرين للمدير:
1. **نسخة قاعدة البيانات**: ينشئ نسخة SQLite آمنة من قاعدة البيانات الحية الموجودة على Render Persistent Disk ثم ينزلها مباشرة.
2. **تصدير كامل Excel**: يصدر جميع جداول CRM الموجودة إلى ملف Excel متعدد الصفحات، بما فيها العملاء وسجلات التواصل والمستخدمون والمتابعات بحسب الجداول الموجودة.

الجداول الموجودة حالياً في قاعدة النسخة البرمجية:
users, companies, interactions, templates

مهم:
- النسخ والتصدير لا يحذفان ولا يعدلان أي بيانات.
- ملف قاعدة البيانات الذي يتم تنزيله من الموقع بعد النشر هو أفضل ملف لإرساله عند طلب تعديلات مستقبلية لأنه يحتوي آخر حالة حية.
- لم يتم حذف أو تغيير أرقام الهواتف الحالية في هذه النسخة؛ تصحيح الأرقام غير الموثوقة يحتاج قاعدة البيانات الحية ومصدر تحقق لكل شركة حتى لا نحذف رقماً صحيحاً أو ننسب رقماً خاطئاً.
