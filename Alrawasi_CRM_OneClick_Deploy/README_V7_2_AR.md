# V7.2 — مزامنة آمنة

تم تعديل مزامنة مقاول لتكون آمنة عند رفض الاتصال:
- عند HTTP 403 أو 401 تتوقف المحاولة فوراً بدلاً من تكرار 8 أخطاء.
- عند HTTP 429 تتوقف المحاولة حتى لا تزيد الطلبات.
- لا يتم تجاوز أو التحايل على حماية منصة مقاول.
- المزامنة إضافة فقط؛ أي عميل موجود لا يتم تعديله.
- المستخدمون وحالات العملاء وسجل التواصل والتعيينات تبقى كما هي.
- يبقى استيراد XLSX/CSV هو مسار الإدخال الاحتياطي للبيانات المصرح بها.
- عند توفر API/تصدير رسمي من مقاول يمكن ربطه لاحقاً دون تغيير قاعدة CRM.
