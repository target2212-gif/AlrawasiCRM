# V7.5.47 — تصحيح المظهر الاحترافي

تم تصحيح المظهر الاحترافي ليطابق التصميم المعتمد بشكل أقرب:

1) الشريط الجانبي الأيمن
- أزيل منه الشعار تماماً.
- أزيل منه رقم الإصدار.
- أصبح مخصصاً للتنقل فقط:
  الرئيسية / الشركات / المستخدمون / سجل التواصل / التقارير والتصدير / الإعدادات والمظهر.

2) الشريط العلوي
- الشعار والهوية يظهران في الرأس العلوي فقط.
- القوائم المجمعة أصبحت:
  البيانات / الحماية والاستعادة / التحقق / المزيد.
- اسم المستخدم وحالة الحفظ الدائم تظهر بصورة مختصرة في الرأس.
- تحديث النظام وحماية البيانات والنسخ والتصدير والتدقيق كلها داخل القوائم المنسدلة.

3) صفحة الشركات
- رأس صفحة احترافي.
- أربع بطاقات إحصائية: إجمالي الشركات، الموثقة، غير الموثقة، المستخدمون النشطون.
- الفلاتر والبطاقات أكثر انتظاماً.
- أدوات الإدارة القديمة لا تتكرر في المظهر الاحترافي.

4) المظهر السابق
- لم يتغير لأي مستخدم.
- المظهر الاحترافي ما زال اختيارياً.
- ألوان كل مستخدم المحفوظة تبقى كما هي.
- إعادة الضغط على المظهر الاحترافي لا تعيد ضبط الألوان المخصصة.

5) البيانات
- crm.db.gz لم يتغير إطلاقاً.
- لا تعديل على الشركات أو المستخدمين أو سجل التواصل أو القوالب.
- التعديل الوحيد في app.py هو استعلامات قراءة لبطاقات الإحصائيات.
