# V7.4.4 — إصلاح أيقونات الشركات
- استبدال الأيقونة السابقة بأيقونة SVG محلية ثابتة.
- لا تعتمد الأيقونة على صور خارجية أو خطوط أو JavaScript، لذلك تعمل على Render مباشرة.
- ملف بيانات مقاول المتوفر لا يحتوي حقلاً لشعار كل شركة؛ لذلك لا يتم اختراع شعارات للشركات.
- إذا توفر لاحقاً رابط شعار موثوق لكل شركة يمكن إضافته مع fallback لهذه الأيقونة.
- بقية وظائف CRM وبيانات العملاء لم تتغير.
