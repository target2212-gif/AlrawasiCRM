# V7.4.9 — مطابقة هواتف Google Maps / Places

- لا يتم استبدال أي هاتف موجود مسبقاً.
- الشركات التي لا يوجد لها هاتف فقط يمكن البحث عنها عبر Google Places API (New).
- المطابقة تعتمد على اسم الشركة مع المدينة/العنوان، ولا تحفظ نتيجة غير كافية.
- عند الاعتماد تحفظ: الهاتف، Google Place ID، اسم نتيجة Google، عنوانها، مصدر الهاتف، وتاريخ التحقق.
- زر فردي داخل صفحة الشركة، وزر دفعات من 1 إلى 50 شركة في صفحة الشركات.
- يحتاج Render Environment Variable باسم GOOGLE_MAPS_API_KEY بعد تفعيل Places API (New).
- قاعدة البيانات المرفقة هي النسخة الحية التي أرسلها المستخدم؛ أما الخدمة الحالية ذات Persistent Disk فتبقى قاعدة /var/data/crm.db هي المرجع ولن تُستبدل عند Deploy.
- النسخ الاحتياطي والتصدير الكامل من V7.4.8 محفوظان.
