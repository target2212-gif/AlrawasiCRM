# V7.5.9 — ترقيم متسلسل + بيانات مقاول + Google Maps

- عرض رقم متسلسل فعلي للشركات حسب ترتيب السجل الداخلي بدون الاعتماد على crm_number القديم ذي الفجوات.
- صفحة الشركة تعرض حقول مقاول التفصيلية عند توفرها: رقم/نوع العضوية، عضو منذ، الحجم، حالة الحساب، الساعات التدريبية، المنطقة، المدينة، العنوان، الهاتف الثابت، الجوال والبريد.
- Google Maps/Places يبحث عن جوال عند غياب الجوال حتى لو كان لدى الشركة هاتف ثابت؛ الهاتف الثابت لا يمنع البحث عن الجوال.
- لا يتم استبدال جوال موجود مسبقاً.
- لا يتم المساس بحالة العميل أو المندوب أو سجل التواصل.
- جلب بيانات صفحات مقاول نفسها يحتاج مرحلة إثراء من المتصفح/JSON لأن Render لا يستطيع الاعتماد على سحب مقاول المباشر عند HTTP 403. الحقول الجديدة جاهزة لاستقبال هذه البيانات بدون إعادة بناء قاعدة البيانات.
- لا تستخدم REBUILD بعد النشر.
