# V7.4.5 — شعارات مقاول + ترقيم داخلي

- يظهر الشعار الحقيقي فقط إذا كان ملف JSON القادم من منصة مقاول يحتوي رابط صورة/شعار فعلي.
- يدعم المستورد عدة أسماء شائعة لحقل الصورة مثل logoUrl و imageUrl و companyLogo والحقول المتداخلة.
- إذا لم توجد صورة حقيقية، يظهر حرف من اسم الشركة كعلامة بديلة واضحة؛ لا يتم اختراع شعار.
- أضيف رقم داخلي خاص بالـCRM بصيغة #1، #2، #3... اعتماداً على رقم الشركة الثابت في قاعدة البيانات.
- الرقم الداخلي لا يغيّر اسم الشركة ولا رقم عضوية مقاول.
- بيانات التواصل والمتابعات والمندوب وحالة العميل محفوظة.
