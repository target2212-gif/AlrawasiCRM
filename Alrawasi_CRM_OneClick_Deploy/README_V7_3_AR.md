# تلال الرواسي CRM V7.3 — تصنيف مقاول

- مصدر الشركات المعتمد: منصة مقاول فقط.
- تمت إضافة حالة التصنيف لكل شركة: مصنفة / غير مصنفة / غير محدد.
- للشركة المصنفة تظهر درجة التصنيف الحالية كما وردت في ملف مقاول المرجعي.
- فلتر العملاء: المصنفة فقط / غير المصنفة فقط / كلاهما.
- صفحة الشركة تعرض ملاحظة واضحة بحالة التصنيف والدرجة.
- بيانات CRM القديمة (حالة التواصل، المندوب، الملاحظات، المتابعات) لا يتم تغييرها.
- قاعدة البيانات المستمرة على Render تبقى في /var/data/crm.db.
- عند أول تشغيل بعد التحديث، تتم إضافة حقول التصنيف وتعبئتها من فهرس مقاول المرفق دون المساس بحالة العميل.
