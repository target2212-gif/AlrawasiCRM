# V7.5.48 — تقارير التواصل الشهرية

تم البناء فوق V7.5.47 مع استخدام أحدث Snapshot رفعه المستخدم كقاعدة Seed حتى لا نفقد أي تواصل سابق.

البيانات المحفوظة في الـSeed:
- الشركات: 17127
- سجلات التواصل: 86
- المستخدمون: 4
- القوالب: 3
- سلامة SQLite: ok

الميزة الجديدة:
- صفحة /reports متاحة لكل مستخدم.
- المستخدم العادي/المدير يرى إنجازه هو فقط.
- مدير النظام Admin يستطيع اختيار مستخدم واحد أو كل المستخدمين.
- فلتر شهري.
- ثلاثة أنواع للتقرير:
  1) تم التواصل معها فقط
  2) لا يمكن التواصل معها فقط
  3) الاثنان معاً
- ملخص شهري لكل مستخدم:
  * عدد الشركات التي تم التواصل معها
  * عدد الشركات التي لا يمكن التواصل معها
  * إجمالي الشركات المنجزة
  * إجمالي سجلات النشاط/محاولات التواصل
- منع تضخيم الإنجاز: الشركة تحتسب مرة واحدة للمستخدم في الشهر وفق آخر نتيجة لها في نفس الشهر.
- تصدير Excel منظم بورقتين: ملخص الإنجاز + تفاصيل الشركات.
- تصدير CSV.
- زر طباعة.
- الروابط داخل التقرير تفتح صفحة الشركة.

الحماية:
- لم يتم حذف أو تصفير أي سجل تواصل.
- تم تضمين أحدث Snapshot الحالي في Seed.
- Neon/PostgreSQL يبقى فعالاً ويستعيد أي سجلات أحدث عند التشغيل.
- المستخدمون وكلمات المرور والتخصصات وإعدادات المظهر الموجودة في Snapshot تم الحفاظ عليها.
- المظهر V7.5.47 بقي كما هو، وأضيفت فقط روابط التقارير.
