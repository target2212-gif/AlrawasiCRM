# V7.4 — واجهة مقاول + خصائص CRM

- عرض الشركات كبطاقات قريبة من أسلوب دليل مقاول، مع الحفاظ على هوية CRM.
- إظهار شعار الشركة إذا كان رابط الشعار متاحاً في ملف المصدر، وإلا تظهر أيقونة شركة افتراضية.
- إظهار مصنفة/غير مصنفة ودرجة التصنيف ورقم العضوية.
- زر خريطة يستخدم الإحداثيات عند توفرها، وإلا يستخدم العنوان والمدينة.
- الإبقاء على حالة العميل والمندوب والمتابعة وواتساب وخصائص CRM السابقة.
- إيقاف المزامنة المباشرة من Render التي كانت تفشل HTTP 403.
- إيقاف Cron الخاص بالمزامنة المباشرة.
- إضافة صفحة «تحديث بيانات مقاول» لرفع JSON.
- الاستيراد يقبل منصة مقاول فقط ويرفض المصادر الأخرى.
- الشركات الجديدة تضاف فقط. للشركات الموجودة يسمح بتحديث بيانات مقاول الوصفية (التصنيف/الدرجة/الإحداثيات/الشعار) ولا يمس حالة CRM أو التواصل أو المتابعات أو المندوب.
